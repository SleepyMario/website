# Sleepy Mario

This is the website of Sleepy Mario, located at [https://www.sleepymario.com](https://www.sleepymario.com), where he writes about a variety of things in an extremely lighthearted and direct style.

The blog is built with Hugo using the Stack theme, which is very easy to use and something I can recommend to anyone. This repository contains the source files used to build and publish the website.

Feel free to have a look anytime.
